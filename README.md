# Resume Builder (Full-Stack MERN Application)

A modern, full-stack **Resume Builder** web application that allows users to create, edit, upload, and enhance resumes using AI. Built with **React, Redux, Node.js, Express, MongoDB**, and integrated with **AI-powered resume enhancement**.

🔗 **Live Demo:**  
https://resume-builder-client-xxxi.onrender.com

---

## ✨ Features

- 🔐 **Authentication**
  - User registration & login using JWT
  - Protected routes for authenticated users

- 📝 **Resume Builder**
  - Create resumes section-by-section
  - Edit personal info, summary, experience, education, projects, and skills
  - Multiple resume support per user

- 🤖 **AI Resume Enhancement**
  - AI-enhanced professional summary
  - AI-enhanced job descriptions
  - Resume data extraction from uploaded PDFs

- 📄 **Upload Existing Resume**
  - Upload PDF resume
  - Automatically extract structured data using AI

- 🌐 **Public Resume Sharing**
  - Toggle resume visibility (public/private)
  - Share public resume via link

- 🎨 **Customization**
  - Multiple resume templates
  - Accent color selection
  - Image upload with background removal (ImageKit)

- ⬇️ **Download & Print**
  - Print-friendly resume preview
  - Download resume as PDF

## 🛠 Tech Stack

### Frontend
- React + Vite
- Redux Toolkit
- React Router
- Tailwind CSS
- Axios

### Backend
- Node.js
- Express.js
- MongoDB + Mongoose
- JWT Authentication
- ImageKit (image uploads)
- AI API integration

### Deployment
- Frontend: Render
- Backend: Render
- Database: MongoDB Atlas
